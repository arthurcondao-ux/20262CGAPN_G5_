# Painel Censo
Objetivo: O presente projeto mostra, através de ferramentas dinâmicas, um Dashboard da Educação com base nos Dados do Censo Educacional de 2024. Mais especificamente, o arquivo agrupa diversas informações sobre distribuição de raça, quantidade e coleta de esgoto e modalidades escolares. O intuito desse projeto é visualizar de forma dinâmica tais distribuições, de forma que suas diferenças sejam claramente ressaltadas visualmente.
Como usar: Abrir o arquivo "Projeto Excel"

## Fonte de Dados
Fonte oficial: Censo Escolar 2024 (INEP)
Link oficial:  https://censobasico.inep.gov.br/censobasico_2024/
O que os dados representam: Os seguintes dados da fonte foram colhidos pelos institutos e associações nacionais, tal como IBGE, e revelam diferentes informações sobre o sistema, qualidade e detalhes sobre a educação no Brasil. 
Estrutura: "NO_Municipio", coluna referente ao município onde tal escola é localizada; "Dependência", coluna referente à qual ente federativo se responsabiliza pela escola; "NO_Entidade", Nome da escola.
